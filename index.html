🔥 Politique de Confidentialité - FirePay

Dernière mise à jour : Février 2026

1. Introduction

FirePay est une application mobile destinée aux Sapeurs-Pompiers Volontaires (SPV) pour le suivi personnel de leurs vacations et indemnités. Nous accordons une importance majeure à la protection de vos données personnelles.

2. Données collectées

L'application collecte uniquement les données que vous saisissez volontairement :

  • Informations de compte : adresse email, mot de passe (crypté)
  • Informations de profil : nom, prénom, grade, centre de secours, taux horaire
  • Données de vacations : dates, heures, types d'activités, montants, statuts de paiement

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Permettre le fonctionnement de l'application
  • Synchroniser vos données entre vos appareils
  • Calculer vos statistiques personnelles

4. Stockage et sécurité

Vos données sont stockées de manière sécurisée sur les serveurs Firebase (Google Cloud Platform) situés dans l'Union Européenne. Elles sont protégées par des protocoles de chiffrement standards de l'industrie.

5. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers. Vos données sont strictement personnelles et ne sont accessibles que par vous.

6. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Accès : consulter vos données à tout moment dans l'application
  • Rectification : modifier vos informations dans les paramètres
  • Suppression : supprimer votre compte et toutes vos données depuis l'application
  • Portabilité : exporter vos données (fonctionnalité disponible dans l'application)

7. Conservation des données

Vos données sont conservées tant que votre compte est actif. En cas de suppression de compte, toutes vos données sont définitivement effacées sous 30 jours.

8. Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez nous contacter à :

Email : contact@firepay.app

9. Modifications

Cette politique peut être mise à jour occasionnellement. Les utilisateurs seront informés de tout changement significatif via l'application.
